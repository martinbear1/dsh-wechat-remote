This project adapts the HTTP JSON request formats, QR confirmation states, text
message construction, inline quoted text, inbound media references/voice text,
AES CDN encryption/decryption, media upload and outbound media messages
and lossless message-ID parser. It adds its own validation,
bounded transport, error handling and host policy. It does not include or require
the OpenClaw runtime. Local limits are not represented as upstream guarantees.
