# 插件与安装器当前基线

更新：2026-09-10。

## 版本与发布

- DSH 插件 `1.7.1`，npm 安装器 `dsh-wechat-remote@1.7.1`。
- 已发布源码 `f39e7a3`，GitHub 正式标签 `v1.7.1`，npm latest 为 `1.7.1`，本轮公开渠道回读确认。
- 本轮仅补充基线说明，不变更运行代码、不覆盖发布资产、不再次发布 npm 包。
- 基线标签 `baseline/plugin-1.7.1-20260910`；原有 `v1.7.1` 不移动。

## 已实现

- Windows x64、macOS Intel、Linux x64；已声明兼容 DSH `0.1.1-rc.2` / `0.1.2-rc.1`。
- 统一安装/升级命令 `npx -y dsh-wechat-remote@latest`；随包提供 pnpm，无需用户另外安装全局 pnpm 或 Git，不升级 DSH 本体。
- WebUI 检查兼容更新、自动备份/安装/重启及失败恢复；保留既有身份、配对、配置和会话。
- 新旧 DSH 原生 API 适配、父子代理 SessionAddress、历史/轨迹/计划/目标及可选轮次用量/用时投影。
- DSH 结构转换留在插件边界；通用能力缺失时隐藏，不修改或修补用户历史文件。
- 安全局域网、端到端加密公网、附件与历史对象传输和断线恢复。

## 验证边界

- 本轮完整 npm test 通过；此前 Windows 公开 npm 冷缓存命令从 1.5.5 升到 1.7.1，以及 WebUI 同源更新 API 从 1.7.0 升到 1.7.1 均有成功记录。
- API 实测不描述为已人工点击按钮；未把全部平台、ARM64、任意进程包装器或所有网络环境标记为已验证。
- 公网支付属于小程序与云端，不要求插件因支付功能另发新版本。
- 通用能力合同不等于 Claude Code 适配器已开发；该节点类型尚未接入。
