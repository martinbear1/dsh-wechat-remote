RC61 群协作组件整理与显式资源能力（2026-10-14）

范围和版本
插件 1.7.14-rc.61；小程序 1.7.11-rc.45；云端 1.2.27-rc.25。
仅本地源码、构建、自动化与隔离原生验证。未发布、上传、部署、安装真实节点或重启真实 DSH。

层级与职责
主包的原生 patch 只包含 gate、ClawBot、微信群协作助手、我的资源四行。
群协作组件管理教师助理、项目助理、定制助手的三个原生声明；preset ID、内置职业定义和现有业务引用不变。
这些模式使用 DSH 原生 registry/register 与 disposer 热挂载；不写宿主默认模式、不改现有会话、不额外安装子包。
底层共享业务服务仍在 gate；群工具和 skill 只在获得声明的 Agent scope 中加载，不移到全局。
三个卡片的独立启停偏好保存到当前节点存储，与账户权益、节点总开关、组件物理开关分开。
关闭再开启节点总开关或组件，不重置单个助手偏好。新偏好缺省为三项开启；实际可用仍要求权益和节点 opt-in。
未为测试设备编写扫描/迁移旧组件禁用状态的逻辑。保留原来三个模块导出，但不再作为新包顶层组件。

真实的停用语义
停用单个助手撤下它的原生预设声明，保留文件、历史和已存在的原生 Agent；不承诺取消已经启动的任务。
关闭群协作节点或整个组件，现有群工具写操作仍由共享门控拒绝。已经开始的其他原生任务不被强制停止。
我的资源组件关闭时只撤下其拥有的资源模式；本地数据保留。普通资源不依赖群协作组件的生命周期。

资源交付
旧 ResourcePreset schemaVersion:1 的含义保持为普通预设。
schemaVersion:2 必须显式给 capabilities:[] 或 capabilities:["wechat-group"]。
群资源必须附带现有 AssistantDefinition 数据；其 name/description/basePreset 与资源外层一致，skills 为 human-workflow。
声明由已有受验证的交付路径提供，不接受插件模块名、脚本或任意可执行组件。声明能力不等于授予账户权益。
普通资源即使继承了教师助理作为 base，也只移除本项目的 collaboration 组件，不改其他原生工具与审批规则。
群资源保留基础模式的原生能力，并追加本项目作用域内协作能力及职业工作方法；作者正文按字面值保留。
资源来源的职业定义接入既有工作实例建档/恢复，保存只读的不可变资源身份，不另造业务账库。
资源组件关闭时仍可只读恢复历史职业定义；原生激活状态与本地定义读取分离，避免启动循环依赖。
本轮不改资源版本/hash/preset ID，不实现已有聊天自动切到新版。RC60 的按版本资源策略保持。
未来云端发 v2 群资源前需部署 RC25 资源交付代码、用户端升级 RC61；旧 v1 仍兼容。无数据库迁移或新的 OSS 权限需求。

小程序边界
wechatFeatures/control 新增 assistant.enabled（teacher/project/designer），返回原有状态并增加可选 groupComponentAvailable。
catalog 和 status 都报告同一可选 enabled 字段。旧插件缺失该字段时，RC45 不展示/发送单助手控制。
外层实验入口偏好、内测标记和权益控制未修改；内层的节点启停和卡片状态仍来自所连接的同一节点。
节点切换/连接换代时丢弃旧结果；不自动重试写操作。组件停用时内页提示到电脑启用，不制造一个新的节点开关值。
当前小程序线上/体验版不会因本地代码变化而自动升级；RC45 未上传。

验证
最终插件 npm test：1493 通过、3 跳过、0 失败；另有内置脚本断言。跳过为旧原生 outline 源码、原生 Connection/exporter 环境与 Windows 不适用的 POSIX symlink。
小程序 unit：1740 通过；真实插件 registry/feature service/Typert 与小程序页面的跨仓回归 2 通过。
云端完整测试：1159 通过（并发限制 4）；包含资源格式与授权/交付回归。
使用本机安装的 DSH 0.2.0-rc.1 ASAR，在临时虚构 profile 验证原生注册、scope、启停、撤权、旧 Agent 与资源恢复；无模型调用、真实账号或真实会话写入。
原生 Loader 单次 root.update 验证三个旧形状组件切为一个群组件，无重复注册/服务冲突；使用当前保留的旧 wrapper，非归档 RC60 包字节的整机升级。
桌面实际 React 视图 6 个隔离布局场景通过；小程序 WXML/WXSS 20 个静态场景通过；这不是 Electron/微信真机交互验收。
bundle、verify、外层安装包的双入口及 402 个 core 文件逐一比对通过。安装包标为无本轮真机兼容证据，不继承以前版本证据。

下一步真机验收（须用户安排）
1. RC60 测试设备主动升 RC61，只保留四个顶层组件；不自动处理其他端。
2. 群组件/节点总开关/单卡片分别启停，检查原生 Agent 预设页与小程序内页；重新打开不得复活单独停用项。
3. 升级 RC45 小程序后验证双端交替操作、返回页面刷新、切换节点、断开连接后的状态。
4. 经授权部署资源交付新格式后，一对一交付普通和群协作各一份资源，验证原生工具+群工具、工作实例恢复与撤权。
5. 主插件及群组件关闭后不得新增群写操作；旧会话/配对/资料保留。
6. 标准/PTC/极简/创造及普通资源模式不加载群工具。上述硬件验收尚未完成。
