## 已确认问题

1. Windows 临时 pnpm.cmd 将 Node 中文绝对路径写为 UTF-8；后台 cmd 按 936 读取时路径错误。外层 chcp 65001 不保证后台环境继承。英文路径对照成功，中文路径复现。
2. 深层 staging-home 改变本地依赖相对路径语义；当前以白名单限制其他插件来源并拒绝外部链接，未覆盖 DSH 官方允许的 Git / file / link 场景。
3. 原生安装失败仅给通用提示，不输出确切日志路径；包装子进程未保留退出码/信号，超时路径需要核对完整退出与回退顺序。
4. 部分 README 仍写旧版本/旧架构范围；官方原生安装备用入口尚未形成独立验收流程。

## 工作顺序

1. 复现测试与安装生命周期审阅。
2. 修复共享工具启动、日志与进程处理；覆盖中文、空格和 Windows 特殊字符，不修改系统代码页/全局 PATH。
3. 原目录调用官方安装，不以其他插件的来源或逐文件摘要作准入条件，不预改其他插件依赖；原生包管理器正常维护依赖及锁文件。不自动放开第三方构建脚本权限。备份仅用于恢复。
4. 检查宿主发现、首次初始化、并发/重复操作、原生退出和启动参数恢复。
5. 构建同一批候选制品并测试四台真实主机的 NPX/全局安装、首次安装、CLI 重装、WebUI 更新与重启、故障回退。
