# 1.7.6-rc.1 任务提醒整合审阅

基于已发布 main 1.7.5，整合 `research/task-notifications-20260914`。本次为 GitHub 预览发布，根插件与内嵌安装器统一 1.7.6-rc.1；不修改 GitHub/npm latest，不修改已发布的 1.7.5 资产。

## 保留的边界

- 插件仅读取原生会话事件和问答执行生命周期；不改 DSH 本体，不替用户回答/授权，不替换原生事件提供者。
- 只在已建立公网身份的 Gate 上注册通知 RPC；两种已有认证传输共用同一接口。可通过 HR_TASK_NOTIFICATIONS_ENABLED=0 管理性禁用，不再依赖临时研发启动脚本。
- 同时最多 16 个观察任务，每轮最多 4 个请求；无任务时无轮询定时器。问答执行的返回值、异常及 next 单次调用保持原样。
- 对已删除、撤销、过期等永久错误终止观察；暂时网络异常不破坏宿主、配对或会话连接。发送结果不明由云端持久化为 unknown，不自动重发。
- 新增原生 Session.snapshotEvents 支持，保留旧 events 形态；标题只取 session/title，不以用户问题正文代替标题。
- 删除了两个针对单台 Windows 的注入/更新脚本，旧版本可从 Git 历史恢复；后续使用正式构建与安装流程。

## 发布通道与待续

- 明确选择 RC 安装器才允许它的内嵌 preview 资产；正式版安装器仍排除在线 preview，完整性/撤回/不降级限制不变。
- 小程序正式发布自动生效：每次同意订阅时，按微信原生运行环境选择 developer/trial/formal，云端提前支持三者，后续送审发布不需要另改服务器。此逻辑位于小程序与云端，不由插件猜测版本。
- 本地测试不等于所有硬件验收；不因本次合并扩大硬件兼容承诺。正式 1.7.5 与 RC 并存，旧小程序的常规功能不依赖通知模块。
