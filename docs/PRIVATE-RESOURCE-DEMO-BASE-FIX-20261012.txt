Private resource demo base correction — 2026-10-12

Root cause
The original demo-creative-companion 1.0.0 and 1.1.0 documents declared
basePreset=agent. In the user's installed DSH 0.2.0-rc.1, the shipped standard
preset ID is standard. The agent row is a host service, not a preset. Native
resolve(agent) throws agent-preset/not-found before codec loading, and the
library reports its generic base/version failure. Download persistence was
successful but activation was not. The earlier simplified fixture used standard
and therefore did not test the exact delivered packages. This was an authoring
and acceptance gap, not an installation or account error by the user.

Correction
Publish new immutable demo revisions 1.0.1 and 1.1.1 with basePreset=standard.
Use exactly the tests/fixtures/private-resources JSON bytes for delivery and
regression. Preserve the original invalid 1.0.0 fixture byte-for-byte so its
failure remains reproducible; .gitattributes disables EOL conversion for these
hashed delivery files. No agent-to-standard silent alias, plugin runtime change,
new plugin package, cloud deployment, old release overwrite or entitlement
expansion. Runtime remains plugin RC46, resource service RC24, mini RC44.
