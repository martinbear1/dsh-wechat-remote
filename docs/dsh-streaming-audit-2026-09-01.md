# DSH 实时流回归审计（2026-09-01）

## 正式参照基线

- DSH 插件：`1.5.5`
- 微信小程序：`1.6.4`
- 云端中继：`1.2.2`

兼容研究分支必须保留这组三端基线已经验证的实时事件、传输批处理、冻结小程序协议和云端透明转发边界。当前分支或当前安装版本只用于定位差异，不能替代正式基线作为验收标准。

## 直接根因

| 层级 | 正式基线行为 | 回归 | 修复边界 |
| --- | --- | --- | --- |
| 插件公网实时通道 | 插件 `1.5.5` 协商 `x-harness-transport-batch`，连续增量通过稳定的批传输路径发送 | 新版 Host 适配器的 `openDshEvents` 直接逐事件发送，绕开了既有批传输路径；高频 token 帧占满小程序单线程收包与渲染 | 新旧 Host 适配器共用同一批传输实现；增量在插件端进行有界归并，边界事件立即刷新 |
| 插件 Host 兼容层 | 旧 DSH 事件直接映射到冻结的小程序协议 | DSH alpha 的标量实时增量和持久化 packed history 形态未在一个边界内归一，且部分会话跟随建立过晚 | 标量实时增量、packed history 防御性输入、会话创建/列表/跟随统一在插件层归一 |
| 小程序共享页面壳 | DSH 状态投影直接驱动会话页 | Claude 共享页面壳改造后，WXML 读取 `pageShell.live`，而 DSH 轻量刷新仍只更新旧的 `view.streamingText/reasoning`；首个完整投影能显示 Think，后续正文不再进入实际渲染槽 | DSH 轻量刷新同步更新通用 `pageShell.live`；连续增量限频渲染，工具边界、完成态和回合边界立即刷新 |

Claude Connector 的业务数据没有进入 DSH reducer；本次 DSH 断流是共享 UI 桥接和插件现代实时通道各自引入的回归，不是 Claude 会话内容污染了 DSH 会话。

## 已排除项

- 云端 `1.2.2` 及当前研究分支都保持业务帧透明转发，不解析或改写 DSH/Claude 会话事件，因此不是本次只出现 Think 的直接根因。
- DSH `0.1.2-alpha.3` 的实时 follow 仍发送标量 `SessionEventEntry`；packed row 是持久化 history/snapshot 形态。插件对 packed live 输入的处理属于防御性兼容，不能据此声称 alpha.3 改成 packed live。
- 模型 API Key 属于用户自己的 DSH/Claude 本体配置，不应由 Connector 或小程序修改，也不应成为连接协议是否成功的条件。

## 实机与自动化证据

- Windows 全局 DSH `0.1.2-alpha.2`：使用同一候选插件完成真实模型提示，收到 `assistant/chunk`、连续归并 delta 和 `turn/end`；一个归并事件覆盖 5 个原始 DSH 序号。
- Windows 隔离 DSH `0.1.2-alpha.3`：首次真实模型检查因隔离 Home 未配置 DSH 自身的模型凭据而返回 `MISSING_CREDENTIAL`；仅为该隔离 DSH Home 复用既有用户凭据后重新运行，完整通过会话创建、历史、模型、提示、`assistant/chunk`、连续归并 delta、`turn/end`、重命名和取消，归并事件覆盖 6 个原始 DSH 序号。测试过程中 Connector 和小程序均未修改 DSH 的模型/API Key 配置。
- 插件完整测试、类型检查、打包验证通过。
- 小程序 231 项测试、冻结协议门禁与包审计通过。
- 云端 74 项测试通过。

这些结果证明 DSH 本体能够产生实时流，插件也能在 alpha.2/alpha.3 上把流翻译为冻结协议；手机端最终体验仍须使用重新编译的小程序做真机回归，不能用桌面测试代替。

## 后续发布门禁

1. 新小程序必须继续支持插件 `1.5.5` 的单一 `seq` 事件；`seqEnd` 只能是可选扩展。
2. DSH 新旧 Host API 差异只能在插件适配层收敛，不能分叉小程序协议或 UI。
3. 局域网和公网必须复用同一 Host 适配器；公网额外保留正式版的批传输能力。
4. 任何 PageShell、Connector 或多节点改造都必须同时回归 DSH 历史、正文实时流、推理、工具调用、队列、权限请求和完成态。
5. 真实模型门禁必须验证首个正文增量、持续增量、工具/推理边界和 `turn/end`，不能只验证 HTTP 请求成功或 WebSocket 已连接。
