# Agent远程管理助手

正式版本：`1.7.16`。

连接微信小程序，在手机上查看电脑里的会话、继续交流和处理任务。支持 DSH Web 与 Desktop，使用各自的节点和配对。

已有安装请使用插件内的“检查更新”，保留原配置、配对和会话，无需先卸载。若提示需要重启，请等待任务结束：Desktop 完整退出再打开；Web 重启实际服务，刷新网页不能替代重启。

新装或旧版本无法一键升级时，请参照[安装与更新说明](https://github.com/martinbear1/dsh-wechat-remote/blob/main/docs/NATIVE-INSTALL.md)，选择对应端的原生安装方式。Web 命令行安装器不用于 Desktop。

完整自动化任务管理需配套新版小程序；手机暂未提供相应操作时，可在电脑端管理。
