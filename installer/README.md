# Agent远程管理助手

DSH 微信连接插件 **1.7.20**。通过微信小程序连接自己的 DSH，查看会话、发送任务，随时接续电脑上的工作。

本版改善新版 DSH 兼容性、历史会话导入与显示设置同步。大文件和显示新功能需配套小程序 1.7.15 或更新版本；旧版小程序可继续使用已有功能。

在 DSH「插件 → 添加插件」中安装 `dsh-wechat-remote@1.7.20`，然后打开「微信连接」，使用小程序「Agent远程管理助手」扫码配对。Web 与 Desktop 分别安装、分别配对。

已有用户通过插件检查更新或原生插件管理器更新，正常升级保留节点、配对与会话。若提示重启，请等任务结束后重启对应 DSH。
